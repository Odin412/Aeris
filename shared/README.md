# Aeris Shared Contracts

The shared workspace defines platform-wide types and constants used by the API, frontend console, and mobile blueprints. Everything ships as simple TypeScript modules so they can be imported directly without a build pipeline.

## Highlights
- `CORE_ROLES` — canonical role names spanning tenants, agents, clients, and investors.
- Domain interfaces covering tenants, onboarding steps, CRM entities, deals, integrations, marketplace records, AI insights, and security artifacts.

These definitions align every phase of the product roadmap with a single source of truth.
